## 快速参考

### 核心颜色
- 主色: `#BD7D31` (暖棕色)
- 背景: `#fcf6eb` (米白色)
- 文字: `#1a1a1a` (深黑)

### 核心字号
- 项目卡片: **14px**
- 正文/服务: **16px**
- 段落标题: **20px**
- 页面标题: **48–60px**

### 核心间距（1rem = 10px）
- 组件间: 4px
- Section: 56px
- 页面级: 80–100px

### 字体
- `Playfair Display` — 所有展示性文字
- `Inter` — 备用正文

---

## 使用 Tokens

1. 安装 Figma 插件: **Tokens Studio for Figma**
2. 导入 `figma-tokens.json`
3. Apply to document
4. 详见 `figma-import-guide.md`
